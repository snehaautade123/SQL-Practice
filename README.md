
## 📌 Key SQL Concepts Covered
- Table creation with constraints (`PRIMARY KEY`, `NOT NULL`, `UNIQUE`, `CHECK`)  
- Data manipulation (`INSERT`, `UPDATE`, `DELETE`)  
- Data definition (`ALTER TABLE`, `DROP TABLE`, `TRUNCATE TABLE`)  
- SELECT queries with filters, sorting, and limiting results (`WHERE`, `ORDER BY`, `LIMIT`)  
- Aggregation functions (`SUM`, `AVG`, `COUNT`, `MIN`, `MAX`)  
- String and date functions (`UPPER`, `LOWER`, `LENGTH`, `CONCAT`, `SUBSTRING`, `TRIM`, `REPLACE`, `EXTRACT`, `AGE`)  
- Conditional logic using `CASE` statements  
- Set operations (`UNION`, `UNION ALL`, `INTERSECT`, `EXCEPT`)  
- Window functions (`ROW_NUMBER()`, `SUM() OVER`)
